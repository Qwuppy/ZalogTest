# Список задач (Todo List)

Простой TODO-лист на React + TypeScript. Тестовое задание для Junior Frontend Developer.

## Демо

https://zalogtest.vercel.app/

## Стек

- React 18 + TypeScript
- Vite
- CSS (без UI-библиотек)

## Функциональность

- Добавление задачи через форму (пустые и строки из пробелов отсекаются)
- Переключение статуса «выполнено / активно»
- Удаление задачи
- Фильтры: все / активные / выполненные
- Счётчик активных задач
- Сохранение в `localStorage` — задачи не теряются после перезагрузки

## Запуск

```bash
npm install
npm run dev
